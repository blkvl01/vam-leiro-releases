# VÁM Leíró – kiadások

A VÁM Leíró program kiadásai és a közös szótár.

- **Letöltés:** a [legfrissebb kiadás](../../releases/latest) `VamLeiro.exe` fájlja. Telepítés nem kell;
  felhasználói mappában (pl. Letöltések) tartsd, hogy az automatikus frissítés működjön.
- **`descriptions.json`:** a közös szótár (angol megnevezés → helyes magyar leírás, anyagok).
  A program induláskor innen frissít. Kézzel ne szerkeszd: a módosítás a programból történik.

A forráskód privát.
